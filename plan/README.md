# 计划（公开摘要）

本目录只放**面向公开的路线图摘要**。

详细的 32 周计划、任务看板、周复盘，以及求职相关记录（求职意向、内部转岗进展、薪资预期）保存在本地，**不进入本仓库**。原因见下。

## 路线图

| 阶段 | 周次 | 主题 | 关键产出 |
|---|---|---|---|
| 一 | 1–8 | 焊接底层与生态 | Zephyr / Micro-ROS + ROS 2 控制 Demo |
| 二 | 9–20 | 机器人核心算法 | 仿真导航 Demo + 自定义 Nav2 插件 |
| 三 | 21–32 | 杀手级项目 | 基于 Zephyr 与 ROS 2 的移动机器人实时导航系统 |

## 技术切入点

以**实时控制**为锚点，向上层 ROS 2 集成与导航算法延伸：

- **大脑**：Linux + ROS 2 + Nav2 —— 感知、决策、规划
- **小脑**：Zephyr RTOS + MCU —— 电机控制、传感器采集、硬实时执行
- **接口层**：`ros2_control` —— 连接两者的标准框架

## 为什么公开与私有分离

本仓库定位是**技术记录**，不是求职材料。因此其中不包含：

- 雇主的代码、文档、截图或任何内部信息；
- 求职意向、内部转岗进展、薪资预期等个人信息。

这样既能长期公开沉淀技术过程，又不会带来不必要的职业风险。
